A fast, single-file portfolio hosted on **GitHub Pages** → **[sserkanakin.github.io](https://sserkanakin.github.io)**. It introduces my background in Data Science & AI, highlights selected projects, and lists how to get in touch.

- **Zero build.** Everything lives in [`index.html`](index.html) — markup, styles, and a small inline script. No framework, no toolchain.
- **Self-contained.** Only external dependency is the Google Fonts stylesheet; the hero artwork is inline SVG.
- **Responsive & accessible.** Works down to phone width with semantic structure and readable contrast.

## Run locally

```bash
# any static server works, e.g.
python3 -m http.server 8000
# then open http://localhost:8000
```

Or just open `index.html` in a browser.

## Deploy

This repository is a GitHub Pages **user site** — pushing to the default branch publishes to `https://sserkanakin.github.io`.
